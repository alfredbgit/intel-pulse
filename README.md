**Purpose:** Competitor intelligence reports for B2B SaaS founders — weekly monitoring delivered to their inbox.

**Requested by:** Alfred Butler

## App Principles

1. **Clean, professional B2B aesthetic** — Stripe/Drip-level credibility
2. **Simple intake flow** — competitor list collected post-payment
3. **Manual-first delivery** — Newman sends reports until automation is built
4. **No fluff** — founders are busy, the page earns trust fast
